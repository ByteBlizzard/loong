# ADR-0001 模块全名规范

**状态**：Accepted（决策者批准，2026-10-29）
**关联**：design.md §11 待决 #1；grammar-v1.md §2.1

## 决策

1. 模块全名采用**反向域名**：`org.example.http`。
2. **主版本作为路径段**：`org.example.http/v2`；省略版本段 = `/v1`。不同主版本是不同模块，可共存于同一构建图（design §7.4）。
3. 段字符规则：`[a-z][a-z0-9_]*`，全小写。
4. **官方保留前缀**：`loong/`（如 `loong.core`、`loong.platform.jvm`）；第三方不得在 `loong.` 域下发布。
5. 本决议同时约束 daemon、CLI、包注册表三者的模块标识表示（同一字符串形态）。

## 理由

- 与 Maven groupId / Java 包名习惯对齐，AI 训练语料中密度最高、歧义最小；
- 反向域名天然防注册表命名冲突；
- `loong/` 官方前缀与附录命名体系一致。

## 替代方案（否决）

- `loong.` 统一前缀（所有模块都住在官方域下）：与生态习惯相悖，注册表需维护二级命名授权；
- 单段短名：全局唯一性无法保证。
